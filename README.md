# 미니PC 발열관리

Firebat F1 미니PC(Ryzen 5 7640HS / Ryzen 7 H 255)의 발열을 줄이는 윈도우 전원 설정을 **버튼 하나로** 적용하는 프로그램입니다.

> Firebat 공식 프로그램이 아니며, 제조사와 관련이 없습니다.
> 있는 그대로 제공되며 어떤 보증도 하지 않습니다. 사용에 따른 책임은 사용자에게 있습니다.

## 할 수 있는 것

방법은 두 가지이고, 하나만 고르면 됩니다.

| 방법 | 바뀌는 것 |
|---|---|
| 부스트 끄기 (99%) | 부스트 끔 + 최대 프로세서 99% → 기본 클럭 근처까지만 (7640HS 약 4.3GHz / H255 약 3.8GHz) |
| 최대 클럭 제한 | 최대 클럭(MHz)만 낮춤. 조용·기본·게임 버튼 또는 직접 정한 값 |

'원래대로 되돌리기'를 누르면 이 프로그램이 만든 전원 계획을 지우고 쓰던 계획으로 돌아갑니다.

최대 클럭 제한의 빠른 선택 값

| 버튼 | 7640HS | H255 |
|---|---|---|
| 조용 | 3.4GHz | 3.0GHz |
| 기본 | 4.3GHz | 3.8GHz |
| 게임 | 4.6GHz | 4.4GHz |

- 클럭 값은 슬라이더나 숫자(MHz)로 직접 정할 수 있습니다(7640HS 2000~5000 / H255 2000~4900).
- 기본 클럭보다 낮게 정하면 실제 클럭이 정한 값보다 더 낮게 나올 수 있습니다. 창에 보이는 실제 클럭을 보고 맞추면 됩니다.
- 지금 실제 CPU 클럭과 제한 위치를 막대로 보여 주고, SSD 온도(창을 연 뒤 최고 온도 포함)도 보여 줍니다.
- 제한을 걸었는데 실제 클럭이 계속 그보다 높으면 알려 줍니다. PC에 따라 한쪽 방법이 듣지 않을 수 있기 때문입니다.
- W(와트) 전력 제한은 바이오스에서 거는 방법을 안내하고, '바이오스로 재부팅' 버튼을 제공합니다.
- 윈도우 전원 계획만 바꿉니다. 드라이버나 다른 프로그램을 설치하지 않습니다.
- 모든 변경은 새로 만드는 '미니PC 발열관리' 전원 계획 안에서만 하고, 원래 계획은 건드리지 않습니다.

## 쓰는 법

1. [Releases](../../releases)에서 zip을 받아 압축을 풉니다.
2. 풀린 폴더 안의 `발열관리 실행.bat`을 더블클릭하고, 관리자 권한 창에서 '예'를 누릅니다.
3. 처음이면 '부스트 끄기 (99%)'를 누릅니다.

처음 실행할 때 윈도우가 경고 창을 띄우면 '추가 정보 → 실행'(또는 '실행')을 누르세요.
자세한 내용은 zip 안의 `사용법.txt`를 보세요.

## 필요한 것

- Windows 10 / 11
- Windows PowerShell 5.1 (윈도우에 기본으로 들어 있음)
- 관리자 권한

F1이 아닌 컴퓨터에서도 켜지고 동작하지만, 그 CPU에 맞는 값인지는 확인하지 않았습니다(창에 주황색 안내가 뜹니다).

## 파일 확인

릴리스마다 zip의 SHA-256 값을 함께 올립니다. 받은 파일이 바뀌지 않았는지 PowerShell에서 확인할 수 있습니다.

```powershell
Get-FileHash .\MiniPC-Cool.zip -Algorithm SHA256
```

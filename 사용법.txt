미니PC 발열관리 v1.0 - Firebat F1 (Ryzen 5 7640HS / Ryzen 7 H 255)
===================================================================

[먼저 읽어 주세요]
- 이 프로그램은 Firebat(파이어뱃)의 공식 프로그램이 아니며, 제조사와 관련이 없습니다.
- 있는 그대로 제공되며 어떤 보증도 하지 않습니다. 사용으로 생기는 문제(성능 저하, 고장,
  데이터 손실 등)의 책임은 사용자에게 있습니다.
- 바이오스 설정은 잘못 바꾸면 부팅이 안 될 수 있으니, 안내된 항목만 본인 책임으로 바꾸세요.
- 라이선스: MIT (LICENSE.txt). 자유롭게 쓰고 고치고 나눌 수 있습니다.

[쓰는 법]
1. 이 폴더를 통째로 미니PC에 복사합니다(USB·구글 드라이브 등).
2. '발열관리 실행.bat' 을 더블클릭 → "이 앱이 변경하도록 허용?" 에서 '예'.
3. 버튼 하나를 누르면 바로 적용됩니다. 처음이면 '추천 · 발열 관리'.
4. 창 아래 '바탕화면 바로가기 만들기'를 누르면 다음부터 바탕화면에서 바로 켤 수 있어요.

※ 처음 실행할 때 경고 창이 뜨면
   구글 드라이브나 인터넷으로 받은 파일은 윈도우가 처음 실행할 때 경고를 띄울 수 있어요.
   - 'Windows의 PC 보호' 창: '추가 정보' → '실행'
   - '보안 경고 - 게시자를 확인할 수 없습니다' 창: '실행'
   압축 파일(zip)로 받았다면 먼저 압축을 푼 뒤 폴더 안에서 실행하세요.
   USB로 옮긴 경우에는 보통 뜨지 않습니다.

설정은 윈도우 전원 계획에 저장돼서 재부팅해도 유지됩니다. 프로그램을 계속 켜 둘 필요는 없어요.
(큰 윈도우 업데이트 뒤에 풀린 것 같으면 다시 켜서 '지금 상태'를 확인하세요.)

[버튼별로 바뀌는 것]
- 추천 · 발열 관리 : 프로세서 성능 강화 모드(부스트) '사용 안 함' + 최대 프로세서 상태 99%
                     → 기본 클럭까지만(7640HS 4.3GHz, H255 3.8GHz).
- 조용 · 저발열     : 부스트 '사용 안 함' + 최대 80% → 기본 클럭보다 더 낮게. 문서·유튜브용.
- 게임 · 성능       : 부스트 '효율적으로 활성화됨' + 최대 100% + 최대 주파수 제한
                     (7640HS 4600MHz / H255 4400MHz). 원래 부스트(5.0 / 4.9GHz)보다 덜 뜨겁게.
- 원래대로 되돌리기 : 이 프로그램이 만든 '미니PC 발열관리' 전원 계획을 지우고, 쓰던 전원 계획으로 돌아갑니다.
                     (그사이 직접 다른 전원 계획으로 바꿨다면 그 계획은 그대로 두고 지우기만 합니다.)

모든 변경은 '미니PC 발열관리'라는 새 전원 계획 안에서만 합니다. 원래 쓰던 전원 계획은 건드리지 않아요.
새 계획은 지금 쓰던 계획을 복사해서 만들기 때문에, 절전·화면 꺼짐 시간 같은 다른 설정은 그대로 따라옵니다.
드라이버나 다른 프로그램을 설치하지 않습니다.
('프로세서 성능 강화 모드'와 '최대 프로세서 주파수'는 원래 제어판에서 숨겨진 항목이라,
 적용하면 제어판 > 전원 옵션 > 고급 설정에서도 보이게 바뀝니다. 되돌리기 후에도 보이는 채로 남지만 아무 영향 없습니다.)

[다른 컴퓨터에서 켜면]
윈도우 전원 설정만 바꾸는 프로그램이라 F1이 아닌 컴퓨터에서도 켜지고 버튼도 동작합니다.
이때는 창 위에 주황색 안내가 뜨고, 기본 클럭 같은 값은 그 CPU에 맞춰 확인되지 않은 상태입니다.
실수로 눌렀다면 '원래대로 되돌리기'를 누르면 처음 상태로 돌아갑니다.

[왜 부스트를 끄고 99%로 묶나]
- 미니PC에 들어간 CPU는 노트북용이라 기본 클럭 근처가 전력 대비 효율이 가장 좋습니다.
- 기본 클럭에서 부스트 클럭까지 올리는 구간은 전력이 급격히 늘어나서, 이 구간만 막아도 발열이 크게 줄어듭니다.
- '최대 프로세서 상태 99%'는 부스트를 쓰지 않고 기본 클럭까지만 쓰게 합니다.
- 99%만으로는 부스트가 완전히 꺼지지 않는 경우가 있어서, '프로세서 성능 강화 모드 끄기'도 같이 겁니다.

[지금 상태 칸 보는 법]
- 실제 CPU 클럭 : 윈도우 성능 카운터로 읽은 평균 클럭. '추천'이면 7640HS 약 4,300 / H255 약 3,800 이하로 떨어져야 정상.
                  (창을 연 직후에는 '읽는 중…'이 몇 초 보일 수 있어요.)
- SSD 온도      : 지금 온도와 괄호 안에 '최고' 온도(창을 연 뒤 가장 높았던 값)를 보여줍니다.
                  창을 켜 둔 채 게임 같은 무거운 작업을 한 뒤 '최고' 값을 보면 됩니다.
                  60℃ 넘으면 주의(주황), 70℃ 넘으면 높음(빨강).
                  SSD가 느려지기 시작하는 온도는 제품마다 다르고, 보통 70~80℃대입니다.
                  디스크가 여러 개면 글자 위에 마우스를 올리면 디스크 이름이 나옵니다.
- CPU 온도      : 윈도우 기능만으로는 정확히 못 읽습니다. 정확한 값은 HWiNFO(무료) 같은 모니터링 프로그램으로 보세요.

[W(와트) 전력 제한은 바이오스에서]
윈도우 설정만으로는 W 제한이 안 걸립니다. 프로그램의 '바이오스 설정 방법 보기'에 순서가 있어요.
요약: Del 로 바이오스 → Advanced 탭에서 Ctrl+F1 → AMD CBS
  · CPU Common Options → Core Performance Boost → Disabled
  · SMU Common Options → System Configuration → 35W (AMD 사양 최저값)
  · 다른 메뉴는 건드리지 말 것

W 제한을 윈도우에서 걸어 주는 다른 프로그램도 있지만 이 프로그램에는 넣지 않았습니다.
- 그런 프로그램은 별도의 하드웨어 접근 드라이버를 설치해서 CPU 전력 설정을 직접 바꿉니다.
  예전에는 윈도우 보안이 막는 드라이버(WinRing0)를 쓰는 경우가 많았지만, 최신 버전들은
  서명된 새 드라이버(PawnIO)로 바뀌는 추세입니다. 쓰려면 그 프로그램의 최신 버전을 받으세요.
- 드라이버와 실행 환경(.NET 등)을 따로 설치해야 하고, 안티치트가 있는 게임과는
  잘 맞지 않을 수 있습니다.
- 재부팅·절전 후 설정이 풀릴 수 있어서, 보통 그 프로그램을 계속 켜 둔 채로 씁니다.
- W를 낮추는 것은 안전하지만, 사양보다 올리거나 전압을 낮추는(언더볼트) 기능은 시스템이
  멈출 수 있으니 건드리지 마세요.
- 드라이버 없이 한 번에 끝내려면 바이오스에서 거는 게 가장 확실합니다.

[고장 예방]
- 작은 미니PC는 열이 쉽게 쌓여서, 오래 뜨겁게 쓰면 부품 수명에 좋지 않습니다.
- F1은 상판이 막힌 구조라 상판 쪽(SSD)이 특히 뜨거워지기 쉽습니다.
- 메모리가 보드에 납땜돼 있어서 고장 나면 수리가 어렵습니다.
- 상단에 팬을 다는 교체 케이스나 써멀 교체로 온도를 더 낮출 수 있습니다.
- 바닥 흡기구가 막히지 않게 받침을 대고, 동봉된 정품 어댑터를 쓰세요.
- 바이오스는 최신 버전인지 확인하고, 온도 제한 같은 다른 항목은 기본값 그대로 두세요.
- 바이오스를 잘못 만져 부팅이 안 되면 메인보드 배터리를 잠시 빼서 초기화할 수 있습니다.

[명령줄로 쓰기 (선택)]
관리자 PowerShell에서:
  powershell -ExecutionPolicy Bypass -File MiniPC-Cool.ps1 -RunAction recommend   (quiet / game / restore / status)
바꾸지 않고 명령만 보기:
  powershell -ExecutionPolicy Bypass -File MiniPC-Cool.ps1 -DryRun -RunAction recommend

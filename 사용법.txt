미니PC 발열관리 v1.1 - Firebat F1 (Ryzen 5 7640HS / Ryzen 7 H 255)
=================================================================

[먼저 읽어 주세요]
- 이 프로그램은 Firebat(파이어뱃)의 공식 프로그램이 아니며, 제조사와 관련이 없습니다.
- 있는 그대로 제공되며 어떤 보증도 하지 않습니다. 사용으로 생기는 문제(성능 저하, 고장,
  데이터 손실 등)의 책임은 사용자에게 있습니다.
- 바이오스 설정은 잘못 바꾸면 부팅이 안 될 수 있으니, 안내된 항목만 본인 책임으로 바꾸세요.
- 라이선스: MIT (LICENSE.txt). 자유롭게 쓰고 고치고 나눌 수 있습니다.

[쓰는 법]
1. 이 폴더를 통째로 미니PC에 복사합니다(USB·구글 드라이브 등).
   네트워크 드라이브가 아니라 PC 안의 폴더(바탕화면 등)에 두세요.
2. '발열관리 실행.bat'을 더블클릭 → "이 앱이 변경하도록 허용?" 에서 '예'.
3. 버튼을 누르면 바로 적용됩니다. 처음이면 '부스트 끄기 (99%)'.
4. 창 아래 '바탕화면 바로가기'를 누르면 다음부터 바탕화면에서 바로 켤 수 있어요.
   (바로가기는 지금 폴더 위치를 가리키므로, 폴더를 옮기면 바로가기를 다시 만드세요.)

※ 처음 실행할 때 경고 창이 뜨면
   구글 드라이브나 인터넷으로 받은 파일은 윈도우가 처음 실행할 때 경고를 띄울 수 있어요.
   - 'Windows의 PC 보호' 창: '추가 정보' → '실행'
   - '보안 경고 - 게시자를 확인할 수 없습니다' 창: '실행'
   압축 파일(zip)로 받았다면 먼저 압축을 푼 뒤 폴더 안에서 실행하세요.
   USB로 옮긴 경우에는 보통 뜨지 않습니다.

설정은 윈도우 전원 계획에 저장돼서 재부팅해도 유지됩니다. 프로그램을 계속 켜 둘 필요는 없어요.
(큰 윈도우 업데이트 뒤에 풀린 것 같으면 다시 켜서 '지금 상태'를 확인하세요.)

[방법은 두 가지 - 하나만 고르면 됩니다]

방법 1. 부스트 끄기 (99%)
  - 프로세서 성능 강화 모드(부스트)를 끄고 최대 프로세서 상태를 99%로 맞춥니다.
  - CPU가 기본 클럭 근처까지만 올라갑니다(7640HS 약 4.3GHz, H255 약 3.8GHz).
  - 숫자를 정할 필요가 없어서 가장 간단합니다. 처음이면 이것부터 써 보세요.

방법 2. 최대 클럭 제한 (클럭만 낮추기)
  - 최대 프로세서 주파수(MHz)만 정합니다. CPU가 그 클럭보다 높이 올라가지 않게 하는 설정입니다.
  - 빠른 선택 버튼(누르면 바로 적용)
      조용 : 7640HS 3.4GHz / H255 3.0GHz  - 문서·영상용, 가장 시원하고 조용함
      기본 : 7640HS 4.3GHz / H255 3.8GHz  - 부스트 없이 기본 클럭까지
      게임 : 7640HS 4.6GHz / H255 4.4GHz  - 부스트를 조금만 씀(원래 5.0 / 4.9GHz)
  - 직접 정하기: 슬라이더를 움직이거나 숫자를 적고 '적용'을 누릅니다(숫자 칸에서 Enter 도 됩니다).
      숫자는 GHz가 아니라 MHz로 적습니다. 예: 4.5GHz → 4500
      7640HS는 2000~5000, H255는 2000~4900 사이에서 정할 수 있어요.
      범위 밖이거나 숫자가 아니면 적용하지 않고 안내만 나옵니다.
      낮출수록 시원하고 조용하지만 느려지고, 높일수록 빠르지만 뜨거워집니다.
  - 기본 클럭보다 높게 정하면 부스트를 그 값까지만 쓰고, 기본 클럭 이하로 정하면 부스트는 끕니다.
  - 기본 클럭보다 낮게 정하면 실제 클럭이 정한 값보다 더 낮게 나올 수 있습니다(CPU가 낮은 구간에서는
    클럭을 촘촘하게 맞추지 못하기 때문입니다). 창의 '실제 CPU 클럭'을 보면서 값을 맞추세요.

어느 쪽이 좋은가
  - 방법 1은 간단합니다.
  - 방법 2는 기본 클럭보다 조금 높게(게임 값 등) 잡으면 성능을 덜 잃으면서 온도를 낮출 수 있습니다.
  - 둘은 동시에 쓰는 것이 아니라, 마지막에 누른 것 하나만 적용됩니다.
  - PC에 따라 한쪽 방법이 잘 듣지 않을 수 있으니, 아래 '제한이 잘 걸렸는지 확인하기'대로 한 번 확인하세요.

원래대로 되돌리기
  - 이 프로그램이 만든 '미니PC 발열관리' 전원 계획을 지우고, 쓰던 전원 계획으로 돌아갑니다.
  - 그사이 직접 다른 전원 계획으로 바꿨다면 그 계획은 그대로 두고 지우기만 합니다.

[제한이 잘 걸렸는지 확인하기]
1. 버튼을 누른 뒤 '지금 상태' 첫 줄이 초록색(● 적용 중)으로 바뀌는지 봅니다.
2. 창을 켜 둔 채로 무거운 작업(게임·벤치마크)을 돌리고, '실제 CPU 클럭'이 정한 값 근처에서 멈추는지 봅니다.
   막대에서는 파란 부분이 빨간 선을 넘지 않아야 합니다.
3. 실제 클럭이 제한보다 계속 높으면 프로그램이 주황색 글씨로 알려 줍니다
   ("실제 클럭이 제한보다 계속 높아요…"). 그 PC에서는 그 방법이 듣지 않는 것입니다.
   이럴 때는 다른 방법(방법 1 ↔ 방법 2)을 써 보거나, 바이오스에서 전력 제한을 걸어 주세요.

[이 프로그램이 바꾸는 것]
- 모든 변경은 '미니PC 발열관리'라는 새 전원 계획 안에서만 합니다. 원래 쓰던 전원 계획은 건드리지 않아요.
- 새 계획은 지금 쓰던 계획을 복사해서 만들기 때문에, 절전·화면 꺼짐 시간 같은 다른 설정은 그대로 따라옵니다.
- 바꾸는 항목(제어판 > 전원 옵션 > 고급 설정 > 프로세서 전원 관리)
    방법 1: 프로세서 성능 강화 모드 '사용 안 함', 최대 프로세서 상태 99%, 최대 프로세서 주파수 0(제한 없음)
    방법 2: 최대 프로세서 주파수 = 정한 값, 최대 프로세서 상태 100%,
            프로세서 성능 강화 모드 = 기본 클럭보다 높으면 '사용', 아니면 '사용 안 함'
    공통  : 최소 프로세서 상태가 5%보다 높게 잡혀 있으면 5%로 낮춥니다(쉴 때 클럭이 내려가도록).
- 되돌릴 때 쓰려고 '이전에 쓰던 전원 계획'을 레지스트리(HKLM\SOFTWARE\MiniPCCool)에 적어 둡니다.
  '원래대로 되돌리기'를 누르면 이 기록도 지웁니다.
- 드라이버나 다른 프로그램을 설치하지 않습니다.
- '프로세서 성능 강화 모드'와 '최대 프로세서 주파수'는 원래 제어판에서 숨겨진 항목이라,
  적용하면 제어판에서도 보이게 바뀝니다. 되돌리기 후에도 보이는 채로 남지만 아무 영향 없습니다.

[다른 컴퓨터에서 켜면]
윈도우 전원 설정만 바꾸는 프로그램이라 F1이 아닌 컴퓨터에서도 켜지고 버튼도 동작합니다.
- 창 위에 주황색 안내가 뜹니다. 값은 그 CPU에 맞는지 확인되지 않은 상태입니다.
- '게임' 버튼은 나오지 않습니다. CPU에 따라 '조용'·'기본' 버튼도 없이 '직접 정하기'만 나옵니다.
- 기본 클럭을 알 수 없는 CPU에서는 '최대 클럭 제한'을 걸어도 부스트를 끄지 않습니다(끄면 정한 값까지 못 올라갈 수 있어서).
- 기본 클럭이 낮은 CPU에서 '부스트 끄기'를 누르면 많이 느려질 수 있습니다(주황색 글씨로 알려 줍니다).
- 켜기만 하면 아무것도 바뀌지 않고, 실수로 눌렀다면 '원래대로 되돌리기'를 누르면 처음 상태로 돌아갑니다.

[지금 상태 칸 보는 법]
- 첫 줄        : 지금 적용 중인 방법. 초록색 ● 표시가 있으면 이 프로그램 설정이 적용된 상태입니다.
- 막대         : 왼쪽 끝이 0, 오른쪽으로 갈수록 높은 클럭입니다(눈금은 GHz).
                 파란 부분이 지금 실제 클럭, 빨간 선과 빗금이 제한으로 막힌 구간이에요.
- 실제 CPU 클럭 : 윈도우 성능 카운터로 읽은 평균 클럭입니다.
                  (창을 연 직후에는 '읽는 중…'이 몇 초 보일 수 있어요.)
- SSD 온도      : 지금 온도와 괄호 안에 '최고' 온도(창을 연 뒤 가장 높았던 값)를 보여줍니다.
                  창을 켜 둔 채 게임 같은 무거운 작업을 한 뒤 '최고' 값을 보면 됩니다.
                  60℃ 넘으면 주의(주황), 70℃ 넘으면 높음(빨강).
                  SSD가 느려지기 시작하는 온도는 제품마다 다르고, 보통 70~80℃대입니다.
                  디스크가 여러 개면 글자 위에 마우스를 올리면 디스크 이름이 나옵니다.
- 맨 아랫줄     : '메인보드 온도(ACPI, 참고용)'가 나오면 CPU 온도가 아니라 보드 센서 값입니다.
                  CPU 온도는 윈도우 기능만으로는 정확히 못 읽으니 HWiNFO(무료) 같은 모니터링 프로그램으로 보세요.

[W(와트) 전력 제한은 바이오스에서]
윈도우 설정만으로는 W 제한이 안 걸립니다. 프로그램의 '바이오스 설정 방법'에 순서가 있어요.
여러 코어를 오래 쓰는 작업(게임·인코딩)의 온도는 클럭보다 전력(W)의 영향을 더 받기 때문에,
이런 작업을 자주 한다면 전력 제한을 같이 하는 것이 효과가 가장 큽니다.
요약: Del 로 바이오스 → Advanced 탭에서 Ctrl+F1 → AMD CBS
  · SMU Common Options → System Configuration → 35W (AMD 사양 최저값)
  · (선택) CPU Common Options → Core Performance Boost → Disabled
    ※ 이 항목을 끄면 부스트가 아예 꺼집니다. 이 프로그램에서 기본 클럭보다 높은
      '최대 클럭 제한'(게임 값 등)을 쓰려면 이 항목은 끄지 마세요.
  · 다른 메뉴는 건드리지 말 것

W 제한을 윈도우에서 걸어 주는 다른 프로그램도 있지만 이 프로그램에는 넣지 않았습니다.
- 그런 프로그램은 별도의 하드웨어 접근 드라이버를 설치해서 CPU 전력 설정을 직접 바꿉니다.
  예전에는 윈도우 보안이 막는 드라이버(WinRing0)를 쓰는 경우가 많았지만, 최신 버전들은
  서명된 새 드라이버(PawnIO)로 바뀌는 추세입니다. 쓰려면 그 프로그램의 최신 버전을 받으세요.
- 드라이버와 실행 환경(.NET 등)을 따로 설치해야 하고, 안티치트가 있는 게임과는
  잘 맞지 않을 수 있습니다.
- 재부팅·절전 후 설정이 풀릴 수 있어서, 보통 그 프로그램을 계속 켜 둔 채로 씁니다.
- W를 낮추는 것은 안전하지만, 사양보다 올리거나 전압을 낮추는(언더볼트) 기능은 시스템이
  멈출 수 있으니 건드리지 마세요.
- 드라이버 없이 한 번에 끝내려면 바이오스에서 거는 게 가장 확실합니다.

[고장 예방]
- 작은 미니PC는 열이 쉽게 쌓여서, 오래 뜨겁게 쓰면 부품 수명에 좋지 않습니다.
- F1은 상판이 막힌 구조라 상판 쪽(SSD)이 특히 뜨거워지기 쉽습니다.
- 메모리가 보드에 납땜돼 있어서 고장 나면 수리가 어렵습니다.
- 상단에 팬을 다는 교체 케이스나 서멀구리스를 다시 바르는 것으로 온도를 더 낮출 수 있습니다.
- 바닥 흡기구가 막히지 않게 받침을 대고, 동봉된 정품 어댑터를 쓰세요.
- 바이오스는 최신 버전인지 확인하고, 온도 제한 같은 다른 항목은 기본값 그대로 두세요.
- 바이오스를 잘못 만져 부팅이 안 되면 메인보드 배터리를 잠시 빼서 초기화할 수 있습니다.

[예전 버전(v1.0)을 쓰던 경우]
- 새 버전을 그냥 실행하면 됩니다. 예전에 적용한 설정은 그대로 남아 있고, 새로 누르면 새 값으로 바뀝니다.
- 예전 '추천'은 '부스트 끄기 (99%)', 예전 '게임'은 '게임' 버튼과 같은 클럭 값입니다.
- 예전 '조용 · 저발열'(최대 80%)은 없어졌습니다. 그 설정을 켜 둔 상태로 새 버전을 열면
  첫 줄에 '값을 직접 바꾼 상태'라고 나옵니다. 같은 용도로 '조용' 버튼을 새로 누르세요.

[명령줄로 쓰기 (선택)]
관리자 PowerShell을 열고, 먼저 이 폴더로 이동합니다.  예: cd "C:\Users\이름\Desktop\미니PC 발열관리 v1.1"
  powershell -ExecutionPolicy Bypass -File .\MiniPC-Cool.ps1 -RunAction boostoff
  powershell -ExecutionPolicy Bypass -File .\MiniPC-Cool.ps1 -RunAction quiet        (base / game 도 같음)
  powershell -ExecutionPolicy Bypass -File .\MiniPC-Cool.ps1 -RunAction clock -Clock 4200
  powershell -ExecutionPolicy Bypass -File .\MiniPC-Cool.ps1 -RunAction restore
  powershell -ExecutionPolicy Bypass -File .\MiniPC-Cool.ps1 -RunAction status
바꾸지 않고 명령만 보기: 위 명령에 -DryRun 을 붙입니다(관리자가 아니어도 됩니다).
  powershell -ExecutionPolicy Bypass -File .\MiniPC-Cool.ps1 -DryRun -RunAction boostoff
